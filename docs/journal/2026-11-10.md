## Findings
- Q1: instantaneous model with a finite source: the middle source layer decays with ks instead of
  ks_inst ('Centerline Output'!B80, 'Plume Output'!C113-C115).
- Q2: first-order plume mass without R ('Plume Output'!P104).
- Q3: BC added twice when two zones have the same concentration (Input!T46-T47).
- Example 1 text: 1837 kg left in the source; screen and workbook: 1873.7 kg.
- Example 2 table: K 8.05E-03 cm/s and R 1.3; input screen: 8.1E-03 cm/s and R 1.2.
- Plume volume counts cells > 0.005 mg/L (manual: > 0); its cell length is dx - 1e-4 ft.
- Instantaneous model with a declining source: the source C0 + BC decays while BC is constant, so
  the source-zone concentration can drop to 0 long before the source mass is depleted
  (e.g. reference case three_zones_retarded).
